## Hi! ✨

I'm Anthony (a.k.a worm jar), half Thai half French, based in Montpellier, France.

I use code and mathematics to create and animate art.

I am always ready to learn about new ways to combine the worlds of Tech and Art; This includes Shaders (GLSL), VFX, Gameplay programming, Procedural/Parametric textures, and much more!

My strength lies in my ability to combine and understand different fields. I specialize in coding and applied Maths, but have a basic grip on 3D Modeling/Sculpting, Texturing, and game design.
This allows me to be useful, no matter the situation!

As a student, it is my job to be curious, and to learn as much as possible about the fields that drives me forward. Being in any opportunity to learn, apply, and concretise is when I shine.

Please do check out my public repositories 😄
